# 文章结构与视觉设计

先根据本篇研究产生独特的场景提示词，再从下列结构与视觉方向中组合，或自行构思。它们是设计线索，不是分支规则、预设场景清单或素材清单。

## 研究结构：表达真实的研究关系

- **随机试验**：人群及随机单位 → 干预与对照 → 随访 → 主要结果；保持两组可比较，写清人数、时间、结局、参照和分析集。聚类随机时显示聚类单位，不把村庄随机画成个人随机；不把复合干预中某个组件单独说成有效。
- **观察性队列或数据库**：队列、暴露、参照、随访与结局的对应关系。多数据源各自保持人群、研究设计、角色与结果；横断面不能装成随访，调查权重和实际人数不要混淆。关联不画成因果。
- **预测或诊断研究**：患者/数据 → 预测时点或检测及参照标准 → 开发与验证或诊断表现；验证队列、阈值和指标按原文区分。没有曲线数据可用真实指标点或简表。
- **系统综述或 Meta**：证据来源、纳入研究/人群及合并效应和不确定性；来自不同研究的数值不冒充新病例。没有各研究效应和区间就不画想象中的森林图。
- **机制与转化**：按真实物种、细胞、组织和人体证据分别呈现系统；局部放大和关系线要与实验支持一致，假说明确标注。不要把体外证据推广成人体疗效。
- **综述或方法**：组织概念、证据类型和已知/未知；不伪装成一项试验的结果。

## 视觉方向：由内容驱动

1. **人群与生活情境**：人、行动及环境是研究主角时，让人物和场景占有足够画面，与对照及真实数据共同讲故事。保持尊重，不以示意图宣称人群个体特征、运动处方或实际患者外貌。
2. **医学主体**：研究真正涉及的器官、局部解剖、病灶或操作有助于理解时，放大相关结构并连到对应结果；位置和关系应有依据，不添加装饰性器官。
3. **临床证据对照**：用相同尺度的并列条件、一个清晰的主要终点和少量说明，适合强调治疗/诊断差异；对照组描述具体。
4. **环境与时间**：用地点或暴露的概念示意连接时间线、测量窗口和结局；不捏造现场、浓度或追踪轨迹。
5. **实验与机制**：以组织/细胞/分子关系或局部放大承载发现；用标注区分已验证与假说。
6. **数据与验证**：用清晰的来源、模型、验证和结果表达方法逻辑；数据流程足以说明问题时无须加入人物器官。
7. **高信息量研究总览**：在可读前提下整合多个关键发现；信息仍按证据来源分区，宁可精简或做补充，不把大量缩小的原图堆成一页。

标题、核心数值及关键组别尽量放大；删去重复的底部总结、冗长脚注和装饰性编号，让画面本身直接讲清发现。关键分母、参照、限制和素材署名不能为了简化而丢失。

用有节制的配色表达信息层级及组别；同一条件始终使用同一颜色，并辅以组名/形状。避免每一部分均等大、均相同圆角卡片的网页模板感；留白、精细线条与视觉主体应服务研究，不用过多装饰或大号数字替代信息。图中文字精炼，重要结论、比较及单位在最终尺寸下可读。采用贴合文章的配色、字体和排版，不把某一颜色和方向绑定某种研究类型。

## 选取合适矢量素材

场景需要真实感或解剖层次时，可先检查本地授权素材、用户提供的可用插图，以及联网可用的开放图形资源，再决定是否自绘；素材需与本篇对象和动作相符。可查 [Bioicons](https://github.com/duerrsimon/bioicons) 等图库中具体图形对应的作者和许可，也可查 [Health Icons](https://healthicons.org/) 中的公开图标；不要假设这些站点的每一项素材使用相同许可，当前来源及可用性按实际核对。真实感不足时不要把简单通用图标说成精确的医学插画。合适素材不可得就如实说明，采用清楚的自绘示意或真实数据图，不阻塞整张图。
